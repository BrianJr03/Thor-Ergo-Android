# Support and testing scope

Thor Ergo 1.0 is a completed personal project shared as an independent fork of
[Armada Dual Screen Input](https://github.com/sa1utyeggs/armada-dual-screen-input).

## Tested setup

The maintainer tested installation from **Windows 11**, using an **AYN Thor Pro
with 12 GB RAM**, on **ArmadaOS 20261109.dfed5d6** (20261109 release).
The upper screen runs Steam Game Mode; **Plasma Mobile must be enabled on the
lower screen** in Armada Control.

The macOS and Linux host installers are provided but **have not been tested by
the maintainer on macOS or Linux computers**. Automated checks are not a
substitute for those real-device tests. Other Thor models, OS releases and every
language/game combination have not been comprehensively tested.

## Maintenance

The project is shared as-is. There is no active maintenance commitment, promised
update schedule, technical-support service or guarantee of compatibility with
future ArmadaOS versions. Community forks are welcome.

Use the bundled Undo, Diagnostics and Wake lower screen operations when needed.
Review diagnostic output before sharing it: it can contain local machine details.
Never publish passwords, SSH private keys or private controller-profile snapshots.
