**Graphic design and keyboard layout: seekingalphacrawler.**

Thor Ergo is an independent fork of
[Armada Dual Screen Input](https://github.com/sa1utyeggs/armada-dual-screen-input).
It is not an official release of AYN, ArmadaOS, Valve or the upstream projects.

## Original software and platform

- **sa1utyeggs and contributors — Armada Dual Screen Input 0.1.7 (MIT).**
  The application foundation, input/session integration and original theme.
- **Ven / venatrix-ritz and Thor Input Contributors — Ratatoskr (MIT).**
  Its input engine and retained components. The original notices, including
  lavachemist, Project Barry, the Decky Loader community and cited research,
  remain in `Thor/app/vendor/ratatoskr/CREDITS.md`.
- **ArmadaOS team.** Device integration, the lower-screen Plasma session and
  companion-screen control.
- **Valve and Gamescope contributors.** The existing compositor and text-input
  interfaces used by the application. These interfaces can change with the OS.
- **ShadowBlip and InputPlumber contributors.** Integration through the existing
  system D-Bus service; the daemon is not redistributed here.

The design credit does not reattribute other developers' code, original theme,
