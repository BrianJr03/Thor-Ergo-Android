# Interface guide / Guia visual

These are **offscreen previews drawn by the application code with native Pango/Cairo**.
They are not photographs or hardware screenshots. The actual Plasma status bar is
not part of the app and is deliberately not simulated. Font rendering and the
available app height can vary with the device session.

As imagens são pré-visualizações do código real da aplicação, não fotografias
do dispositivo. A barra do Plasma não é desenhada pela aplicação.

## Main keyboard — English (US)

The main page has no arrow keys. Enter, @ and / share the bottom-left row; the touchpad stays on the right.

![Main keyboard — English (US)](images/keyboard-en.png)

## Teclado principal — Português (Portugal)

O teclado português mantém a cedilha. As legendas refletem o estado de Shift e Caps Lock.

![Teclado principal — Português (Portugal)](images/keyboard-pt.png)

## Numbers and punctuation

Use 123 to open this page, ABC to return to letters, and Sym. for additional symbols. Arrow keys are available here.

![Numbers and punctuation](images/numbers.png)

## Symbols

Additional symbols and explicit accent/dead keys. Enter and navigation remain in the lower section.

![Symbols](images/symbols.png)

## Function keys

F1–F12, editing keys, modifiers and navigation. Fn is accessible from the top bar.

![Function keys](images/functions.png)

## Accent popup

Hold an eligible letter, slide to the desired accent and release. This example selects ã in the Portuguese keyboard.

![Accent popup](images/accent-popup.png)

## Languages

Keyboard layout and interface language can be chosen independently. Follow keyboard automatically matches them.

![Languages](images/settings-languages.png)

## Language picker

Choose among seven keyboard languages. This changes the application, not the system-wide keyboard layout.

![Language picker](images/language-picker.png)

## Keyboard preferences

Adjust accent hold time, Backspace/arrow repetition and the Caps Lock double-tap interval.

![Keyboard preferences](images/settings-keyboard.png)

## Mouse preferences

Adjust pointer and scroll speed, tap-to-click and inertial glide.

![Mouse preferences](images/settings-mouse.png)

## AYN button

The screenshot shows the default Off state. Enable with games closed; wait for Ready before trying the physical button.

![AYN button](images/settings-ayn.png)

## About and credits

## Mode menu

Switch between the combined layout, keyboard and touchpad views.

![Mode menu](images/mode-menu.png)

## Offline Pinyin

Type a Latin Pinyin sequence and select a candidate. This is basic offline composition, not contextual prediction.

![Offline Pinyin](images/pinyin.png)
