# ThorKBM

## 2.2

- **In-app updates:** ThorKBM tells you when a new version is out, shows
  what's new, and installs it for you. Check any time in Settings → About,
  or turn off the check on start there.
- **Smaller "Open keyboard" button:** the hidden keyboard now shows a small
  + key instead of a wide button. Choose its corner in Settings → Keyboard.

This version has to be installed by hand once. Later updates install from
inside the app.
