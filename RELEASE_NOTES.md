# ThorKBM

## 2.3.0

- **Opens from Command Panel:** with Command Panel 0.10.0 or later, tap the
  ThorKBM button or the Keyboard tile in its panel and the keyboard takes
  the panel's place on the lower screen. Hide brings the panel back.
- **Lower screen power while opened from Command Panel:** Command Panel
  controls turning the lower screen off, so ThorKBM's own button is hidden
  until you close the keyboard.
