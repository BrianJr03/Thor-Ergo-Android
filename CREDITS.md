# Credits and provenance

**Graphic design and keyboard layout: seekingalphacrawler.**

ThorKBM is a native Android fork of Thor Ergo, the ArmadaOS version, which is
itself an independent fork of
[Armada Dual Screen Input](https://github.com/sa1utyeggs/armada-dual-screen-input).
It is not an official release of AYN, ArmadaOS, Valve or the upstream projects.

## Original software whose behaviour this edition reimplements

- **sa1utyeggs and contributors — Armada Dual Screen Input 0.1.7 (MIT).**
  The application foundation and the original input design.
- **Ven / venatrix-ritz and Thor Input Contributors — Ratatoskr (MIT).**
  The trackpad gesture engine ported to `core/trackpad`. Its license and
  credits, including lavachemist, Project Barry, the Decky Loader community and
  cited research, are in `licenses/ratatoskr/`.
- **ArmadaOS team.** The platform the 1.0 edition was built for.

## Android edition

- **Shizuku** by RikkaApps, Apache-2.0, for privileged input injection.
- **HiddenApiBypass** by LSPosed, Apache-2.0.
- AndroidX, Jetpack Compose, Dagger/Hilt and kotlinx libraries (Apache-2.0).

## Language data

- **Qing Lee — xpinyin 3.1 data**, derived from Unihan 14.0.0. The LPPL notice,
  the unmodified source data and the reproducible index builder are retained in
  `licenses/xpinyin/` and `tools/pinyin/`.
- **Unicode, Inc. and contributors.** The original character-reading data.

## Artwork

The glove pointer sprites were created for Thor Ergo; their provenance is in
`licenses/THIRD_PARTY.upstream.md`.

libraries. These credits are also shown in **Settings → About & credits**.
