# Upstream provenance

Thor Ergo is an independent fork of **Armada Dual Screen Input** by
**sa1utyeggs and contributors**, based on version **0.1.7**.

- Upstream: https://github.com/sa1utyeggs/armada-dual-screen-input
- Source baseline: https://github.com/sa1utyeggs/armada-dual-screen-input/tree/v0.1.7
- This fork: https://github.com/seekingalphacrawler/Thor-Ergo

The original Git ancestry is retained. This fork's complete installable source
is under `distribution/Thor/app/`; that is the runtime shipped in Thor Ergo.
The upstream application's `VERSION` remains its original provenance marker;
`ERGO_VERSION` and the root `VERSION` identify this fork as **1.0**.

Original copyright and third-party notices are retained. The redesigned interface,
national layouts and deployment tools do not transfer authorship of upstream
code to the layout designer. See CREDITS.md and distribution/Thor/app/THIRD_PARTY.md.

**Graphic design and keyboard layout: seekingalphacrawler.**
