The unmodified input xpinyin-database.def is included here. Source and complete original work:
https://ctan.org/pkg/xpinyin
https://github.com/CTeX-org/ctex-kit/tree/master/xpinyin
Original data comes from Unihan_Readings.txt (Unicode 14.0.0).
Changes: reverse index, tone removal, ü represented by v, ordering of common characters.
This derivative is named pinyin-index.json, not xpinyin. Maintenance status: unmaintained.
The build-data script and manually supplied phrase list are provided with the release.
No TeX program or font is bundled or required. This file is dictionary data, not a font.
The UI is simplified Chinese; the character table also contains traditional/rare characters.
This is a basic, deterministic candidate engine, not a sentence-prediction or learning IME.
